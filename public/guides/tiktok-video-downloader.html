TikTok video downloader

Use VGSAVE to check a supported public TikTok video URL and download an available video quality from your browser.

How to download a supported public TikTok video

  1. Open the public TikTok video you are authorized to download.
  2. Copy the video URL.
  3. Open VGSAVE and paste the URL into the downloader.
  4. Let VGSAVE check the available media formats.
  5. Select an available video quality and start the download.

The available choices depend on the source. VGSAVE cannot create a quality that the source does not provide.

Why a TikTok download may fail

  • The video is private, restricted, removed, or requires an account.
  • The source URL is incomplete or no longer points to available media.
  • The source platform has changed how the public video is delivered.
  • A temporary network or service error occurred.

If detection fails, try copying the public URL again and check the download troubleshooting guide.

Choosing video quality

Higher resolution can produce a sharper file but usually requires more storage. The quality list shown by VGSAVE is based on formats available from the supplied source. For more detail, see the video quality guide.

Can I download any TikTok video?

No. VGSAVE is intended for public content that you own or are authorized to download. It does not provide a way to access private content, bypass account restrictions, or defeat access controls. Respect copyright, privacy, and the rules that apply to the source content.

Mobile and desktop

VGSAVE is browser-based, so the same basic workflow can be used on supported Android, iPhone, iPad, Windows, macOS, and other modern browsers. For device-specific tips, see the Android guide, iPhone guide, or PC guide.
