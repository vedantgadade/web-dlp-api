How VGSAVE decides what to show

VGSAVE checks the supplied public URL before a download starts. The service uses information available from the source to determine which media formats and qualities can be offered. This means two different URLs can show different options even when they look similar.

VGSAVE does not create missing source quality, unlock private media, or guarantee that a source will remain supported. Source platforms can change their systems at any time.

Common reasons a download does not work

  • The URL is private or requires an account.
  • The media has been removed or is unavailable in the current region.
  • The source format is not currently supported.
  • The source platform has changed how the public media is delivered.
  • A temporary network or service error occurred.
